# History

This module is the AMQP sampler the OneDroid Argus runner drives through `templates/message-flow.jmx` and
`templates/amqp-load.jmx`. It is maintained in this repository. The Java package is
`com.onedroid.jmeter.amqp`.

It was vendored from an earlier standalone sampler project. That project was Apache-2.0 and this directory keeps
its own `LICENSE` (Apache-2.0); the rest of this repository is MIT.
